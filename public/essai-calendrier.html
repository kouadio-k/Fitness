Ajouter les séances au Calendrier

On cherche la méthode que l'iPhone accepte. .

    Essaie les méthodes dans l'ordre

    Dès que Calendrier affiche les séances avec « Tout ajouter » (ou « Ajouter »), note la lettre : c'est la bonne méthode.

    Dans la feuille de partage, cherche Calendrier. S'il n'y est pas, choisis « Enregistrer dans Fichiers », puis ouvre le fichier depuis l'app Fichiers.

    Le test en 3 étapes

    1. Ouvre cette page dans Safari et essaie A, B, C, D. Garde « 1 semaine (essai) » pour ne pas remplir le calendrier.
    2. Ensuite, ajoute cette page à l'écran d'accueil (Partager → « Sur l'écran d'accueil ») et refais l'essai depuis l'icône « Essai agenda ». C'est ce mode qui imite l'appli.
    3. Supprime les séances d'essai dans Calendrier (touche une séance → « Supprimer l'événement »), puis l'icône « Essai agenda ».

    Pour chaque étape, dis-moi ce qui s'est passé avec chaque lettre : Calendrier s'ouvre, rien ne se passe, message d'erreur… Une capture d'écran suffit.
